# Car Maintenance Tracker

A relational database project for **CSC 370: Database Systems** at the University of Victoria. The project models vehicle owners, vehicles, maintenance records, service types, and parts.

## Files

- **`requirements.md`** – Describes the purpose, requirements, and scope of the database.
- **`ERD.png`** – Entity-Relationship Diagram showing the database entities and relationships.
- **`schema.md`** – Relational schema derived from the ERD, including keys and relationships.
- **`database.sql`** – Creates the database tables and inserts sample data.
- **`queries.sql`** – Contains SQL queries used to demonstrate and test the database.

## Running the Project

1. Run `database.sql` in MySQL Workbench to create and populate the database.
2. Run the queries in `queries.sql` to test the database.

## References & Tools

- **CSC 370 course materials** – Database design, normalization, relational algebra, and SQL concepts.
